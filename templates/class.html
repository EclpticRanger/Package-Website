Stack

Creating A Stack

To make a stack varable just do the fallowing

My_stack = Stack()

Push()

Pushing a varable to a stack add it to the top

My_stack.push(value)

Pop()

Poping the stack removes the top items form stack

My_stack.pop()

Peek()

Peeking the stack returnes the top value in the stack

Top_value = My_stack.peek()

Is_empty()

Cheeks if the stack is empty and returs a bool weather it is

if My_stack.is_empty():
do thing if empty

Size()

Returns the amount of items in the stack

Stack_size = My_stack.size()

Queue

Creating A Queue

To make a queue varable just do the fallowing

My_queue = Queue()

__repr__()

Returns the queue for debuging

print(my_queue.__repr__())

append()

Adds the Value to the end of the queue

my_queue.append(my_value)

appendleft()

Adds the Value to the start of the queue

my_queue.appendleft(my_value)

pop()

Removes a value from end of the queue

my_queue.pop()

popleft()

Removes a value from start of the queue

my_queue.popleft()

clear()

Removes all items form the stack

my_queue.clear()
